# W5 SU(2) structural basis contract

## Purpose

`scripts/bqg_w5_su2_structural_basis.py` enumerates admissible representation
labels for a fixed ten-link K5 spin assignment. Its support is defined only by
SU(2) tensor-product rules; no amplitude cutoff, numerical coefficient, CG
overlap, or eigensolver output is consulted.

## Conventions

All spins are doubled integers. For two representations,

`s1 tensor s2 = |s1-s2|, |s1-s2|+2, ..., s1+s2`.

At a four-valent node, pair channels are
`K12 in s1 tensor s2` and `K34 in s3 tensor s4`.

* Gauss-singlet labels obey `K12=K34=K`.
* An explicit charged source label obeys
  `|K12-K34| <= J2 <= K12+K34` and
  `K12+K34+J2 = 0 mod 2`, with all `M2=-J2,-J2+2,...,J2`.

The covariant K5 key is `(spins, labels)`: four nodes carry `("G",K)`;
the selected source carries `("C",J2,M2,K12,K34)`. This matches the label
conventions used by the existing covariant K-leg implementation.

## W5 seed

The five frozen seeds have ten doubled link spins equal to 4 and node labels
`K=(0,2,4,6,8)`. Their source-covariant embedding uses `J2=M2=0` and
`K12=K34=K` at the source node.

## Scope and non-claims

This is an exact representation-theoretic *ambient basis* for each supplied
spin sector. It is not the operator-reachable support of the full 24-term
epsilon KKV map. The operator may occupy a strict subspace because of
intertwiners, orientation, holonomy-index contractions, volume blocks and
coherent cancellations. Conversely, this generator does not decide whether
a coefficient is nonzero.

The full W5 reachable-basis problem still requires a word-aware support
propagator through the actual forward and independently reversed-adjoint
operator words, with every intermediate link-spin sector represented. No
physical projector, HDA closure, or nonzero physical kernel is implied.


## Exact dimension of the initial W5 spin sector

For the frozen seed spin assignment `spins=(4,)*10` (ten links with
physical spin j=2), every node has local quartet `(4,4,4,4)`.

* Each ordinary Gauss node has five singlet channels: `K=0,2,4,6,8`.
* The complete charged source factor has 625 labels when all allowed `J2`,
  magnetic `M2`, and `(K12,K34)` channels are included.
* With one charged source and four Gauss nodes, the full factorized ambient
  covariant basis therefore has
  `625 * 5^4 = 390625` label keys.

This is a finite, exact combinatorial count for one fixed link-spin sector.
It is **not** the size of the operator-reachable W5 subspace and does not
include other spin sectors generated by holonomy hits.

## Implementation threshold warning

The existing operator path still contains coefficient-based filtering below
the final matrix accumulator. In particular, the covariant projection and
charged-node decomposition routines use small absolute cutoffs when retaining
recoupling overlaps, and the covariant completion conversion has a default
tolerance. Therefore using the fixed-basis matrix assembler at the final stage
does not by itself make the current W5 computation threshold-free. A genuinely
threshold-free coefficient pipeline requires exact structural projection
support plus unpruned coefficient propagation at every intermediate stage.


## Word-aware link-spin support

The generator now also contains a conservative propagator for the repository's
Peter-Weyl word format. A `P` path applies one fundamental hit to each
successive edge; in doubled-spin labels each hit allows only
`s -> s-1` or `s -> s+1`, subject to the declared link cutoff. A `V`
operation leaves link spins unchanged. The adapter
`t_sequence_spin_support` imports the actual `T_sequences` and
`adjoint_sequence` definitions from the existing Peter-Weyl engine, avoiding
a duplicated operator-word template.

For a representative frozen triple with `(v,a,b,c)=(0,1,2,3)), initial
`spins=(4,)*10`, and `Jmax2=10`, the edge-hit multiset is:
`(0,3)` twice and `(0,1),(1,2),(0,2)` once each. The edge-spin-only
superset therefore contains `3 * 2^3 = 24` link-spin assignments before
local intertwiner constraints. This count is a combinatorial consequence of
the word's hit pattern, not a computed KKV amplitude.

This propagator still does not impose magnetic-index CG non-vanishing,
four-valent tensor overlap support, volume-block matrix zeros, or coherent
epsilon cancellation. It is deliberately an upper bound. The next layer must
propagate admissible node labels over these spin sectors and then compare the
resulting conservative support with actual unthresholded coefficient columns.
