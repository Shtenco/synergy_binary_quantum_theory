# Finite SU(2) holonomy quotient audit (2026-11-18)

## Scope

This gate isolates a kinematic issue left open by the two-sided endpoint-QFI
parameterization. It does not derive a BQG dynamical law or a QFI metric. It
determines which endpoint coordinates describe the same link-holonomy
variation, which directions are generated by vertex gauge transformations,
and which infinitesimal holonomy data remain after vertex gauge reduction.

## Conventions and exact differential

For an oriented edge (e=(u,v)), let (g_e\in SU(2)) and use
\[
g_e\mapsto h_u g_e h_v^{-1}.
\]
Choose anti-Hermitian generators (T_a=-i\sigma_a/2), with
\([T_a,T_b]=\epsilon_{ab}{}^cT_c\). Write
\[
h_u(t)=e^{t\xi_u},\qquad h_v(t)=e^{t\xi_v}.
\]
Then
\[
\delta g_e=\xi_u g_e-g_e\xi_v,\qquad
\delta g_e g_e^{-1}=\xi_u-\operatorname{Ad}_{g_e}\xi_v.
\]
This is a left-trivialized tangent in the Lie algebra at the identity.

More generally, introduce two endpoint coordinates
\[
g_e(t)=e^{t x_{e,u}}g_e e^{-t x_{e,v}}.
\]
The map from six real coordinates to the three left-trivialized link
coordinates is
\[
H_e=[I_3\; -\operatorname{Ad}_{g_e}].
\]
Since the adjoint matrix is invertible, (\operatorname{rank}H_e=3) and
\(\dim\ker H_e=3\). Its kernel is
\[
x_{e,u}=\operatorname{Ad}_{g_e}x_{e,v},
\]
which produces (\delta g_e=0). This is an overcomplete endpoint
description of one group element. It is not evidence for a new physical
edge-frame gauge symmetry.

## Vertex gauge versus cycle holonomy

Collecting all edges gives a block-diagonal endpoint map (H). The
vertex-to-endpoint embedding (B) assigns the same vertex parameter to
every incidence at that vertex. Their composition is the graph gauge
Jacobian
\[
A=HB,\qquad
(A\xi)_e=\xi_u-\operatorname{Ad}_{g_e}\xi_v.
\]
The infinitesimal physical tangent quotient has dimension
\[
d_{\rm mod}=3|E|-\operatorname{rank}A.
\]
The stabilizer dimension is (3|V|-\operatorname{rank}A); it depends on
the holonomies, not only on the graph.

For a connected tree, every edge holonomy can be gauged to the identity.
The generic orbit rank is (3(|V|-1)), its stabilizer is the global
(SU(2)) of dimension 3, and (d_{\rm mod}=0).

For a graph with one independent cycle, the remaining gauge-invariant datum
is the conjugacy class of the ordered loop holonomy. A generic (SU(2))
element has a one-dimensional Lie-algebra centralizer, so the orbit
stabilizer has dimension 1 and the local quotient has dimension 1. The trace
of the loop holonomy is a finite gauge-invariant coordinate for this
conjugacy class (away from singular endpoints of its range).

## Finite numerical control

The executable gate uses a three-node path and a four-node single cycle,
constructs noncommuting (SU(2)) link matrices, and checks:

- orthogonality and composition of the adjoint representation;
- rank 3 of every six-to-three endpoint map and its three-dimensional kernel;
- composition of the endpoint map with the vertex incidence embedding;
- finite gauge covariance of the ordered cycle holonomy;
- agreement of the analytic infinitesimal law with a finite-difference
  derivative;
- zero local holonomy moduli on the tree and one on the generic single cycle.

The script exports detailed singular values and residuals to
`verification_results/Q2_RELATIONAL_HOLONOMY_QUOTIENT.json`.

## Interpretation and limitations

This closes only the finite (SU(2)) kinematic quotient for the stated
oriented-link convention. It corrects the interpretation of the previous
six-endpoint-coordinate map: those six variables are not six physical
edge degrees of freedom. No independent edge-frame field was introduced,
so no additional edge-frame gauge symmetry is asserted.

This result is not yet the quotient of the normalized boundary-state ray.
That projective stabilizer can be larger and state-dependent. Nor does the
present calculation derive a BQG measure, a physical edge QFI, a map to the
causal-PL graph, or a continuum limit. The next bridge must compare the
holonomy quotient Jacobian with the projective boundary-state tangent and
identify which holonomy moduli survive the actual contraction map.
