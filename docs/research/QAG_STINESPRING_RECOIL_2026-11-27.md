# QAG Stinespring and recoil checkpoint

**Date:** 2026-11-27  
**Scope:** finite-dimensional quantum-information model. This is not a gravity simulation.

## Model

Added `qag_stinespring.py`. The Hilbert space is
\[
\mathcal H_S\otimes\mathcal H_R\otimes\mathcal H_P\otimes\mathcal H_A,
\]
where (S) is the two-branch source register, (R) is a source recoil momentum lattice, (P) is a probe momentum lattice, and (A) is a neutral two-level pointer.

In branch (L), recoil and probe momenta are unchanged. In branch (R), the model applies paired cyclic shifts
\[
T_R(-q)\otimes T_P(+q),
\]
so the modular total-momentum phase is exactly conserved by the controlled translation. The ordinary centered momentum-label mean is only a diagnostic because a cyclic shift is not generated by a globally defined linear momentum operator at the wrap seam.

The pointer receives a controlled (y)-rotation
\[
|0\rangle_A\mapsto R_y(\theta)|0\rangle_A.
\]
Its branch-state overlap is
\[
\langle 0|R_y(\theta)|0\rangle=\cos(\theta/2),
\]
which controls how much which-branch information leaks into the pointer and therefore suppresses interference in the reduced probe state.

After source postselection, the code retains recoil and pointer registers, then traces them out to obtain the conditional probe density matrix. A second function evaluates both outcomes of a complete orthonormal source measurement.

## Wrap-seam diagnostics

The result now reports `recoil_wrap_probability` and `probe_wrap_probability`. These are the unconditional probabilities, weighted by the initial branch-(R) population, that the corresponding branch-(R) cyclic translation crosses the array seam. They are not postselection-conditioned probabilities and are not a substitute for a non-cyclic momentum model. A low value is necessary for interpreting the lattice approximately as an unbounded momentum axis; a high value flags that interpretation as invalid.

The implementation also validates finite Gaussian centers and pointer angles. The unused intermediate global-state construction was removed; the source amplitudes are contracted directly with the selected measurement ket, while recoil and pointer remain explicit environment indices.

## Tests

`tests/test_qag_stinespring.py` covers:
- normalized positive conditional probe state;
- exact conservation of the modular total-momentum phase after averaging over the complete outcome ensemble;
- pointer branch overlap and its effect on the reduced probe state;
- completeness of both source measurement outcomes;
- zero-impulse control;
- wrap-seam diagnostics for packets deliberately placed near the cyclic boundary;
- invalid impulse and non-finite parameter rejection.

The QAG CI workflow compiles and executes this module and its tests.

## Interpretation limits

1. The momentum lattice is cyclic. The exact conserved quantity is the modular phase operator
   \[
   W=\exp[2\pi i(P_R+P_P)/N],
   \]
   not the ordinary centered label sum. The latter is seam-sensitive. Interpreting the lattice as ordinary unbounded momentum still requires negligible wrap probability.
2. The pointer is an abstract neutral two-level register. It records branch information, but is not a spatial detector with a calibrated energy/momentum budget.
3. The branch impulse is an explicit toy translation, not derived from a dynamical gravitational source field. The recoil register is bookkeeping, not yet a relativistic source model.
4. Conditional postselection can change the probe's conditional mean. The compensating recoil is included in the same conditional state; no net momentum creation is implied.
5. The current code uses pure initial register states and a rank-one projective postselection. Mixed-state preparations, general POVMs, and explicit measurement-apparatus dynamics remain future extensions.

## Next closure gates

- add mixed initial states and general POVM outcomes;

No claim of physical antigravity, net propulsion, or violation of momentum conservation follows from this model.
