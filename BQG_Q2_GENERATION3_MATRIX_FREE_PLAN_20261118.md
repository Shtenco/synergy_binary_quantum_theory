# Generation-3 matrix-free Feshbach plan

## Objective

Extend the audited q=2 PL-to-causal correspondence from generations 0–2 to generation 3 without constructing a dense \(N_{PL}\times N_{PL}\) matrix or a dense \(N_{PL}\times N_c\) isometry.

The exact generation-3 sizes from the barycentric f-vector recurrence are:
\[
(f_0,f_1,f_2,f_3)=(40256,261440,442368,221184),
\]
with 221,184 PL tetrahedra, 442,368 dual adjacencies, and 512 causal coarse fibres.

## Matrix-free representation

Store one integer fibre label \(a(x)\in\{0,\ldots,N_c-1\}\) for each PL dual vertex \(x\), fibre sizes \(s_a\), and the sparse 4-regular dual adjacency. Do not materialize \(U\).

The isometry \(U:\mathbb R^{N_c}\to\mathbb R^{N_{PL}}\) acts as
\[
(Uz)_x=\frac{z_{a(x)}}{\sqrt{s_{a(x)}}}.
\]
Its adjoint is
\[
(U^Tv)_a=\frac{1}{\sqrt{s_a}}\sum_{x:a(x)=a}v_x.
\]
The projection \(P=UU^T\) is simply fibre-wise averaging:
\[
(Pv)_x=\frac{1}{s_{a(x)}}\sum_{y:a(y)=a(x)}v_y,\qquad Qv=v-Pv.
\]

For any coarse vector \(z\), compute
\[
Bz=QLUz
\]
by applying the sparse graph Laplacian \(L=4I-A\) to \(Uz\), then subtracting the fibre-wise mean of the result.

For any fine vector \(v\), compute
\[
B^Tv=U^TLQv
\]
using the sparse Laplacian and fibre sums. This gives matrix-free products with \(B\) and \(B^T\).

The excluded-sector operator is applied as
\[
Hv=QLQv.
\]
A nonsingular full-space solver can use \(H+P\), exactly as in the current generation-1/2 implementation.

## Coarse Feshbach operator without storing all right-hand sides

For a coarse vector \(z\), calculate:
\[
b=Bz,\quad Hx=b,\quad Cz=B^Tx.
\]
Thus \(C=B^TH^{-1}B\) is available as a matrix-free positive-semidefinite operator on only 512 coarse variables. Use Lanczos/eigsh on this coarse operator to estimate \(\|C\|_2\), rather than solving 512 right-hand sides and storing a 221,184-by-512 solution matrix.

For the first frequency derivative:
\[
\Sigma'(0)z=B^TH^{-2}Bz,
\]
perform a second solve \(Hy=x\), then return \(B^Ty\). This is again a matrix-free coarse operator.

The Galerkin block \(A_{PP}=U^TLU\) can be built from the sparse quotient conductances already computed by fibre adjacency counts. The effective operator \(A_{\rm eff}(0)=A_{PP}-C\) is then also a 512-dimensional matrix-free operator.

## Exact combinatorial generation

A generation-3 PL tetrahedron is one maximal flag of nonempty faces inside a generation-2 tetrahedron. Each generation-2 tetrahedron yields exactly 24 such flags. Generate the 221,184 child flags in a deterministic order.

For dual adjacency, each child flag has four codimension-one faces. Emit four records (sorted 3-face key, child id, omitted rank). Sort the 884,736 records by the three-integer face key; every key must occur exactly twice. The two records produce one dual edge, and the omitted rank gives its route colour. This avoids a Python dictionary of tuple-heavy face-incidence objects.

The causal fibre label for each child must be generated by the existing causal-child, parent-face-side, vertex-face-colour, and permutation/orientation rules without changing their semantics. Preserve the exact child-to-parent map and verify all four route colours at every child dual vertex.

## Required validation gates

1. Exact generation-3 f-vector and Euler characteristic.
2. Exactly 221,184 dual vertices and 442,368 dual edges.
3. Every dual vertex has degree four; every codimension-one face has exactly two incident tetrahedra.
4. All four route colours occur exactly once at each dual vertex.
5. Causal-to-PL map is surjective and adjacency preserving.
6. Pushforward measure total remains 16 and parent mass is conserved by refinement.
7. Matrix-free \(U^TU=I\) and \(P^2=P=P^T\) randomized residual controls.
8. Matrix-free \(Bz\), \(B^Tv\), and \(A_{PP}\) agree with the current dense implementation at generations 1 and 2 to a stated tolerance.
9. \(C\succeq0\), \(0\preceq A_{\rm eff}(0)\preceq A_{PP}\), and the constant mode is the unique zero mode.
10. Report solver residuals, iteration counts, Q-sector gap estimate, \(\|B\|_2/\|A_{PP}\|_2\), \(\|C\|_2/\|A_{PP}\|_2\), and the first self-energy derivative.

## Numerical strategy and failure policy

Use sparse CSR/edge arrays for the PL dual graph, integer fibre labels, and fibre-reduction arrays. Use matrix-free projected conjugate gradients with a documented preconditioner. Use Lanczos for the Q-sector gap and coarse Feshbach operator norms. Record solver tolerances and convergence metadata.

If the projected gap becomes too small for reliable CG, do not report an unqualified Feshbach number. Switch to a stronger preconditioner or a shift-invert/deflated solver and report an interval/error estimate. Do not silently regularize \(H\), because that changes the Feshbach operator.

The generation-3 result must be marked **finite combinatorial / unweighted PL Laplacian**. It must not be described as physical QFI, continuum gravity, or an emergent spacetime result.

## Mathematical reason for this design

The finite Schur complement is the constrained energy minimum:
\[
z^TA_{\rm eff}(0)z
=\min_{q\in Q\mathcal H}(Uz+q)^TL(Uz+q).
\]
The matrix-free algorithm computes this same object. It changes only the representation and solver, not the projection, inner product, graph Laplacian, or physical interpretation.
