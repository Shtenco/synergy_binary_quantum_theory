# BQG V25 — локальный аудит за пределами сжатого W17 и контроль зарядовых сокращений

**Дата:** 2026-11-08. **Статус:** реальные конечномерные E-only данные из архивов V12/V13 и 12 ориентированных K5 H_E^sine скалярных выходов; **новых полных лоренцевых SU(2) амплитуд не получено**. Ни C1, ни C2, ни off-shell HDA, ни физический TT не закрыты.

## A. Новый нижний сертификат мощности выхода за W17

Пусть P — ортогональная проекция на W17, Q=I-P; E=E_0 — полный E-only оператор, действующий из W17 в общий выходной гильбертов носитель. Архив V12 содержит `rank(PEP)=2`, `rank(EP)=17`, `smin(EP)=2.0081387278495684`. Для 15-мерного K=ker(PEP), при x∈K имеем PEPx=0, значит QEPx=EPx и ||QEPx||≥smin(EP)||x||. На ортонормированном базисе K:

    rank(QEP|_K)=15;
    ||QEP||_F >= sqrt(15)*smin(EP) = 7.777487849835527;
    ||(-2/3)QEP||_F >= 5.184991899890351;
    ||(-2/3)QEP||_op >= 1.3387591518997122.

Доказательство — точная линейная алгебра **при условии**, что сохранённые ранги и сингулярные числа V12 корректны. Погрешность исходных SU(2)-амплитуд не получила интервального сертификата. В частности, эти 15 нулей сжатия не являются физическим ядром полного E_0.

## B. Новый условный no-go для *внутреннего* W17-компенсатора HDA

V12 сообщает, что все десять ненулевых выходов C_r=[E_0,E_r]Ω ортогональны W17 (в пределах численной точности опубликованных overlap). Составим матрицу C с десятью пробными столбцами и полный остаток R=(4/9)C+K, где K включает все остальные каналы и независимый D в том же **PL16** выходном пространстве. Тогда:

    ||R||_F² = ||P K||_F² + ||(4/9) C + Q K||_F².

Если K целиком внутри W17 (QK=0), то:

    ||R||_F² = (4/9)² ||C||_F² + ||K||_F²;
    ||R||_F >= (4/9)*7.608464409020511 = 3.3815397373424494.

Также ||R||_op >= (4/9)*σmax(C) = 1.4089562273711063. Если K имеет внешние компоненты, то необходимо `||QK||_F >= 3.3815397373424494` для точной компенсации, и непременно `PK=0`, `QK=-(4/9)C`. Общая нижняя оценка: `||R||_F >= max(0, 3.3815397373424494 - ||QK||_F)`.

**Научная граница:** `D` не вычислен, настоящий K не измерен; это условная структурная теорема для 10 начальных коммутаторных проб, а не всеобщее no-go БКГ. Численную ортогональность из V12 нельзя объявлять доказанной точно до сертификации амплитуд.

## C. Первичные ориентированные K5 H_E^sine: проблемы для полного зарядового сертификата

Из точного исходного GitHub JSON (`blob SHA 078c311c74c0131d09ecacefe57b9eb7735b30ea`, успешный Actions run 42136642363) восстановлены 12 наборов скалярных норм по ориентациям. Они являются **индивидуальными ориентациями одного входного базисного состояния**, а не полной суммой по всем 12 ориентациям.

Результаты:

- 12 ориентаций; сумма отдельных `raw2` = **2.0697524883561496**, а сумма квадратов примитивных вкладов = **5.449934043565411**; оба числа **не являются** нормой полной когерентной суммы 12 ориентаций.
- Ориентации **0 и 3** имеют опубликованное `raw2=0`, но `projected2=5.88966789636e-32` и `6.32105184559e-32`. Для идеальной ортогональной проекции `||Pψ||² <= ||ψ||²`; точные напечатанные числа этому противоречат. Масштаб ~1e-16 в амплитуде соответствует возможной численной потере точности, а не физической аномалии.
- Ориентация **6**: `raw2=7.718124510711135e-19`, `projected2=5.462260098408433e-32`, `incoherent2=0.45531606300320676`. Отношение примитивной нормы к когерентной ~**7.680696346e8**. Это чрезвычайно чувствительный режим сокращения. Полагать `postsum_leak` физическим без интервальной ошибки нельзя.
- 9 ориентаций помечены `MEASURABLE_COHERENT_OUTPUT`, 3 (`0,3,6`) — `CANCELLATION_DOMINATED_NOT_CERTIFIED`. **Полная charge covariance не доказана.**

### Найдено точное численное место риска в исходном операторном отчёте

`bqg_he_sine_true_coherent_charge_orientation.py` (Git blob `569e3de43df7b9dafdfc941830671b446b6d23b5`) накапливает блоки Gram через `total += np.einsum(...)`, затем возвращает `max(0., total.real)`. Это может скрыть отрицательный округлённый результат сильного сокращения, а `projected2` рассчитывается отдельно. Отдельные локальные регрессионные тесты V25 показывают, почему отрицательный Gram до обрезки должен логироваться и считаться `NUMERICALLY_INDETERMINATE` до пересчёта, а не точным нулём.

Предлагаемое воспроизводимое продолжение: сохранить полный комплексный `raw` по ориентациям 0/3/6, пересчитать Gram с управляемой погрешностью либо более высокой точностью, выполнить **общую** когерентную 12-ориентационную сумму в одном Hilbert-базисе и лишь затем проверить `||(I-Pcharge) H_E ψ|| / ||H_E ψ||`. Не смешивать K5 с PL16.

## D. Поправка к стандарту V2/V4 сертификата

Численный V2/V4-PASS при относительной ошибке <1e-10 **недостаточен без границ ошибок расчёта**, особенно при компенсации больших комплексных ветвей. Если независимые a,b получены с *сертифицированными* норменными ошибками `ea`, `eb`, то истинное относительное расхождение не превосходит

    (||ahat-bhat||+ea+eb) / max(||ahat||-ea, ||bhat||-eb)

при строго положительном знаменателе (при условии, что округления вычисления нормы и разности включены в `ea,eb`). V25-валидатор возвращает `NOT_CERTIFIED_MISSING_ERROR_BOUNDS`, даже если приближённые состояния полностью совпадают, но нет внешних сертификатов погрешности. На проверенных модельных контрольных входах действует fail-closed.

## E. Что проверено локально

Запущены 57 тестов из архивного V22, 31 из V23, 49 из V24 и 46 новых из V25. **Итого 183/183 PASS** (включая 8 дополнительных тестов точного двоично-рационального суммирования Gram). Тесты используют настоящие сохранённые конечномерные итоговые данные, а искусственные матрицы только как отрицательные/положительные проверки программных тождеств; полные исходные SU(2)-операторы локально не исполнялись.

Из GitHub доступны success logs run 42136642363, но нет артефактов с полными комплексными 12-ориентационными состояниями; логи содержат только скалярные результаты для каждой ориентации.
