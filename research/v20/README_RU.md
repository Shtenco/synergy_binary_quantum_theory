# БКГ V20 — локальное продолжение (7 ноября 2026)

## Что действительно сделано

1. Использована настоящая архивная комплексная матрица Грама `G_EE` K5 W5 (исторический запуск GitHub Actions 42121958625, Git blob 0231c54d2e9a7fc9401995c999d3989f3f1f7648), сохранённая в `SOURCE_SNAPSHOT.json` из пакета V19. Отдельно независимо проверена целостность локального JSON: SHA256 `950423420850c887f8facb747be66a44cc4ed007655c6b04aac8ce21b347dbc9`.
2. Выведена и проверена **теорема о минимальной компенсирующей норме для физического ядра заданной размерности**. Пусть `A` — общая карта пяти реальных евклидовых узлов, `A†A=G_EE`, а `H=aA+Q`, `a=-2/3`, `Q=-32/9 S+R`, действующий на ТОМ ЖЕ W5 и ОБЩЕМ выходном гильбертовом пространстве. Если `dim ker H >= k`, то

   `||Q||_2 >= |a| sqrt(lambda_k(G_EE))`,
   `||Q||_F >= |a| sqrt(sum_{j=1}^k lambda_j(G_EE))`,

   где eigenvalues упорядочены по возрастанию. Условие необходимо, **не достаточно**. Оценки точны в пространстве произвольных матриц: пример `Q=-a A P_k`, где `P_k` — проектор на k наименьших собственных векторов `G_EE`, достигает обоих порогов и даёт ровно k нулевых мод. **Этот искусственный пример не есть физический S или R БКГ.**

   | Желаемое dim ker H >= k | Минимальная операторная норма Q | Минимальная норма Фробениуса Q |
   |---:|---:|---:|
   | 1 | 3.7955274555 | 3.7955274555 |
   | 2 | 3.8191603201 | 5.3844232947 |
   | 3 | 3.8656831329 | 6.6283874585 |
   | 4 | 3.8941943223 | 7.6876699799 |
   | 5 | 4.0499638293 | 8.6892161176 |

3. Получена **точная рациональная** нижняя оценка Гершгорина для **напечатанных десятичных коэффициентов** исходной матрицы. Без округления квадратных корней: `lambda_min(Gprinted) >= 30986014705888919694296245097028693/10^33 = 30.986014705888919694296245097028693`. Для комплексных элементов применено неравенство `|x+iy| <= |x|+|y|`. Проверена строгая эрмитовость именно десятичных строк и отказ при нарушении. Если погрешность любой из 25 комплексных записей не превышает `delta` в абсолютном значении, тогда `||Delta G||_2 <= 5 delta`; гарантированная положительность сохраняется при `delta < 6.19720294117778`. **В самой БКГ верхняя граница ошибки матричных элементов НЕ измерена**, поэтому это не интервальное утверждение о точном SU(2) операторе.
4. Отдельно для PL16 и десяти истинных евклидовых коммутаторов `C` с `sigma_min(C)=1.3241893190` доказана серия необходимых **ранговых** границ для остатка `R = (4/9) C + K`: если `rank(K)<=r<10`, тогда `||R||_2 >= (4/9) sigma_min(C) = 0.5885285862` и `||R||_F >= sqrt(10-r)*(4/9) sigma_min(C)`. Здесь `K` включает все остальные коммутаторы и независимый D; сам K не вычислен.
5. Написан `pl_v20_stage_worker.py`: производственный вызывающий исходные `C(V)`/`C(K)` по **одному** из 3 последовательных шагов в точном порядке original V2, с единственной фильтрацией `J2 in (0,2)` сразу после шага 2, с комплексными непороговыми checkpoint NPZ, SHA256 и проверкой общих параметров при восстановлении. Локально протестированы mock-компоненты, сериализация и отказы. **Сам реальный PL16 backend отсутствует в локально смонтированном архиве V19; ни один реальный тяжёлый SU(2) V4-путь тут не выполнен.** Схема сохраняет исходный оператор и готова к запуску в полном checkout, когда он доступен.
6. `test_v20.py`: 18 локальных unit-тестов PASS, в том числе конструктивное достижение всех пяти порогов для абстрактной линейной алгебры. Тесты с искусственными операторами **никогда не считаются физическими амплитудами**.

## Как воспроизвести

```bash
python -m pip install numpy
python v20_rank_thresholds.py --source SOURCE_SNAPSHOT.json --out RESULTS_V20.json
python -m unittest -v test_v20
```

Для настоящего первого stage физического V4 в ПОЛНОМ оригинальном checkout с замороженным commit:

```bash
PYTHONPATH=scripts python scripts/pl_v20_stage_worker.py \
  --stage 1 --commit YOUR_40_HEX_SOURCE_COMMIT --volume-backend tetrahedral_volume_backend \
  --source-node 0 --omit 0 --cycle 0 --mode forward --order p --aux 0 0 0 \
  --output-prefix out/v20_000_stage1
```

Второй шаг указывается с тем же набором параметров, `--stage 2`, `--previous-prefix out/v20_000_stage1` и иным `--output-prefix`; аналогично третий. Сохранённый 41harged NPZ **не является** физической Gauss-проекцией целого слова: следует когерентно сложить все 8 ветвей, потом проектировать, и сравнить с V2 по комплексным коэффициентам. Ложные PASS-заявления запрещены.

## Чего это НЕ доказывает

Не получено ни одного нового настоящего комплексного Lorentzian C(K)/C(V) состояния: полный V4 32/32, эквивалентный V2, физический Q, замкнутая HDA с независимым D, контролируемое уточнение, физический проектор, TT-полюс и низкоэнергетический предел ОТО **открыты**. Нет новой экспериментальной предсказательной константы. W5 K5 и C3 PL16 — **разные носители**, между ними нет незаконного соединения матриц.
