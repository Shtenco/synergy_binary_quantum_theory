# BQG V21 C1 — независимый локальный численный sanity-check

Этот каталог содержит **самостоятельный синтетический тестовый стенд** для проверки базовых численных свойств, строгой обработки JSON-метаданных, целостности V2 NPZ-артефактов, полноты V2 acceptance checks и проверки обязательных физических диагностик, обсуждавшихся при ремонте V21 C1.

## Запуск

```bash
python -m unittest discover -s . -p 'test_*.py' -v
```

## Что проверяется

- суммирование действительных и мнимых частей через `math.fsum`;
- устойчивость нормы L2 через последовательный `math.hypot`;
- underflow/overflow-safe поведение нормы;
- относительная ошибка на малых масштабах без искусственного нижнего порога знаменателя;
- точное различение нулевого и ненулевого состояния;
- сохранение субпороговых остатков в точной ветке;
- зависимость legacy incremental pruning от порядка входов;
- строгая граница `abs(value) > threshold` в синтетической legacy-модели;
- fail-closed сравнение при `NaN`/`Inf`;
- сравнение объединения ключей двух разреженных состояний;
- запрет bool/float вместо целочисленных auxiliary/path selectors;
- строгие типы source selectors и checkpoint support counts;
- строгая проверка V2 term metadata, SHA-256, NPZ схемы, формы массивов, конечности амплитуд, уникальности ключей support count и полноты обязательного набора из девяти V2 acceptance checks, наличия четырёх leakage-диагностик и неотрицательности/конечности projection norms и строгой проверки числовых типов (без bool и строк).

## Критически важное ограничение

Это **не** тесты производственного кода репозитория и **не** замена 78 тестам `tests/test_v21_c1_checkpoint_repair.py`. Файлы `test_metadata_guards.py` и `test_v2_artifact_guards.py` содержат изолированные копии guard-функций, чтобы проверить логику типов и NPZ-проверок локально; они не импортируют production-модули. V2 guard требует точного набора из девяти ключей production acceptance checks и отклоняет неполный или расширенный набор. Diagnostic guard требует четыре явно присутствующие конечные неотрицательные числовые leakage-диагностики и конечные неотрицательные числовые projection norms; bool и строки отклоняются. Текущий runtime не содержит checkout репозитория; поэтому здесь не запускались production-скрипты V21/V2, не читались настоящие NPZ checkpoints, не выполнялись 32 V4 пути и не пересчитывались четыре V2 эталона.

Никаких утверждений о доказательстве C1, HDA, физического TT-сектора или ОТО этот пакет не делает.
