# Информационно-голографические мосты БКГ: строгие конечные тесты

**Редакция:** 2026-11-09. Связанный документ: [корневой научный README](../../README.md), главы 33–40.

Эта папка содержит *точно проверяемые конечномерные математические утверждения*, демонстрирующие связь выбранных информационно-геометрических конструкций BQG с языком кодирования и тензорных сетей. Применение стандартных теорем о кодах и тензорных сетях к выбранному носителю не означает доказательства физической голографической дуальности БКГ и не доказывает их научный приоритет.

## Три конечных математических шага

**I. Бинарный тетраэдр и изометрия.** Для четырех меток $a,b\in\{0,1\}$ берутся Walsh-знаки $((-1)^a,(-1)^b,(-1)^{a\oplus b})/\sqrt3$. Их скалярные произведения равны $-1/3$ для различных меток. Свяжем метку с тремя выходными двоичными флажками:

$$
V\lvert a,b\rangle=\lvert a,b,a\oplus b\rangle.
$$

Все четыре кодовых базисных вектора различны и ортонормированы; отсюда $V^\dagger V=I_4$. Для любого оператора $O$ на четырехмерном логическом пространстве $V^\dagger(VOV^\dagger)V=O$ — глобальная реконструкция на кодовом подпространстве. Из любых двух **классических** флажков восстановима исходная метка, однако код не исправляет произвольные стирания одного физического кубита для всех квантовых суперпозиций. Это не полноценный голографический квантовый корректор ошибок.

**II. Cut-entropy bound.** Для чистого нормированного состояния, образованного конечной тензорной сетью с фиксированными входами, любой разрез $C$ между наборами открытых физических индексов дает разложение не более чем по $\prod_{e\in C}\chi_e$ связанным виртуальным индексам. Отсюда:

$$
\mathrm{SchmidtRank}(\Psi)\leq\prod_{e\in C}\chi_e,
\qquad
S(\rho_L)\leq\sum_{e\in C}\ln\chi_e.
$$

В графе $Q_4$ есть 16 вершин и 32 ребра. Разрез по одному двоичному координатному разряду содержит ровно 8 рёбер. Если **дополнительно выбрать** для каждого пересекаемого ребра виртуальную размерность $\chi_e=2$, тогда $S(\rho_L)\leq 8\ln2$, или максимум 8 бит. В абстрактной сети из восьми пар Белла на этом разрезе верхняя граница достигается. Это не вывод энтропии чёрной дыры Бекенштейна–Хокинга из оригинального SU(2)-гамильтониана БКГ.

**III. Коarse-graining стены.** Среди восьми бинарных кирпичиков ровно с четырьмя светлыми существует $\binom84=70$ различных микросостояний, соответствующих одному среднему наблюдаемому значению. Скрытая в этом усреднении классическая информация равна $\log_2 70\approx6.1293$ бит. Это не физическое уничтожение информации и не доказательство голографического принципа.

## Запуск воспроизведения

Из корня репозитория в окружении с `numpy`, `sympy`:

```bash
python research/holography_20261109/verify_holographic_bridge.py
```

Выход сравните с [RESULTS.json](RESULTS.json). Проверяются exact Walsh inner products и frame-матрица, однозначность parity-кода, изометрия, глобальное восстановление, невозможность универсального quantum-erasure вывода, счет Q4 и saturation via Bell pairs. Символические тождества вычисляются SymPy, численные тесты насыщения — NumPy.

## Открытые физические требования

Нужно вывести физическое пространство после всех ограничений; строго определить boundary/horizon и локальную boundary algebra; показать физическое quantum error correction или entanglement wedge reconstruction; вывести площадь горизонта, коэффициент $1/4$, само законное действие HDA и наблюдаемый взаимодействующий гравитон. Пока все это остаётся открытым.
