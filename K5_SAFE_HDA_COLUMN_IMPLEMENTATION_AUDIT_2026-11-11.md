## 1. What the safe-column implementation actually computes

The safe-column script:
1. Represents the ten K5 links with doubled integer spins and four-valent intertwiner labels.
2. Builds normalized four-valent invariant tensors from SU(2) Clebsch–Gordan coefficients.
3. Inserts orientation epsilon maps on legs whose edge orientation is reversed.
4. Builds the local volume from the collective triple product (\epsilon_{abc}J_1^aJ_2^bJ_3^c), followed by the positive square root of its absolute value.
5. Builds each primitive (T)-word from a volume insertion and holonomy-path hits.
6. Constructs a Hermitian completion by adding the primitive word and a separately constructed adjoint word with coefficient (1/2).
7. Applies (H_0H_1-H_1H_0) to one initial K5 spin-network basis vector with all ten links at (j=1/2) and all five recoupling labels (K_v=0).
8. Separately applies (H_0) to the legacy five-tetrahedron (V_5) vector.
9. Reports support, norms, fixed-all-(j=1/2) fraction, maximum spin reached, and regression differences from hard-coded reference numbers.

It is explicitly a **single safe HH column**, not all ten commutator pairs, not a full matrix on the 816-dimensional one-hit habitat, and not a physical HDA closure test.

## 2. Cutoff argument: valid for the stated two-hit column, not automatically beyond it

The reachability script models each local word as two hits on its radial edge and one hit on each of three triangle edges. A fundamental holonomy hit changes doubled spin by (pm1). Thus one local (H_v) can change a given edge by at most two half-spin steps, and a two-H history can change a given edge by at most four half-spin steps.

Starting from (j=1/2), the largest possible spin after four upward steps is (j=5/2). The reachability gate reports that this upper wall is actually attained by allowed Gauss-admissible histories. Therefore (J_{\max}=5/2) is the correct saturated cutoff for the **specific HH histories from the all-(j=1/2) input** described by this word.

This does not imply (J_{\max}=5/2) is sufficient when applying (H_v) to every vector in an already enlarged depth-one shell, then generating depth two, or iterating to greater shell depth. The maximum spin bound must be recomputed from the number of hits in each history. A depth-(d) shell master action probes one more Hamiltonian application than the shell-generation depth, so its regulator wall must cover that additional action.

## 3. Threshold cascade: the principal numerical-certification weakness

The safe-column code has several distinct amplitude thresholds:
- `add_dict` drops entries at approximately (10^{-13});
- `apply_primitive_oriented` drops local projection coefficients below (10^{-12}), then final outputs below (10^{-11});
- `apply_T_cached_state` drops combined outputs below (10^{-10});
- `compose_on_sparse` and the top-level run prune at (10^{-8}).

The graph-shell wrapper adds another `prune_state(..., 1e-10)` layer.

These are not one global tolerance. Repeated thresholding is nonlinear with respect to cancellation and can make results depend on where aggregation occurs. The hard-coded regression targets (with a (5\times10^{-8}) pass tolerance) detect some changes to the final scalar outputs, but they do not bound the cumulative discarded vector norm and do not prove that the threshold cascade is harmless.

### Required repair

- Keep all amplitudes through each complete algebraic aggregation step, or use a single documented final threshold after coherent summation.
- Record for every threshold stage the number of dropped keys, dropped (\ell_1) amplitude, and dropped (\ell_2) norm.
- Run a tolerance ladder (for example (10^{-8},10^{-10},10^{-12},10^{-14})) and deterministic insertion-order permutations.
- Report the change in commutator vector norm, fixed-sector fraction, and (V_5) image norm.
- Establish a conservative bound on the accumulated discarded vector, not only on each individual dropped coefficient.

## 4. Adjoint construction must be independently certified

The code constructs the adjoint of a primitive sequence by reversing the operator list; volume insertions are retained, while holonomy paths are reversed and their input/output magnetic indices are exchanged. This is structurally plausible, but source inspection alone is not an adjointness proof for the complete implementation.

The required independent test is a matrix-element identity on a representative set of basis states:
[
\langle x,T y\rangle
=\langle T^\dagger x,y\rangle,
]
and, after the Hermitian completion,
[
\|H-H^\dagger\|/\|H\|
\]
must be measured **before any explicit symmetrization**. Test both orientation choices, every path type, boundary spins, and all allowed recoupling labels. The test should also distinguish exact algebraic adjointness from errors introduced by finite cutoff or pruning.

The current code does not expose a full operator matrix for all sectors, so these tests can be implemented as sparse action-level bilinear probes without materializing the entire Hilbert-space matrix.

## 5. Volume operator: do not hide the anti-Hermitian defect

`volume123_matrix` forms the epsilon-contracted triple product (Q), then replaces it with ((Q+Q^\dagger)/2) before diagonalization. Mathematically, the exact triple product on three distinct link factors should be Hermitian under the stated conventions. The implementation should therefore record
[
\delta_Q=\frac{\|Q-Q^\dagger\|}{\max(\|Q\|,\epsilon)}
]
before symmetrization. It should also record the eigensolver residual for the Hermitian matrix and the residual of the reconstructed square-root operator. Symmetrization can remain as a roundoff cleanup only after the raw defect has been shown to be at numerical-noise scale.

## 6. Scope of the current regression

The safe-column regression compares three final quantities against hard-coded targets:
- commutator norm;
- fixed-all-(j=1/2) norm-squared fraction;
- (H_0V_5) norm.

It also requires that (H_0V_5) have no fixed-all-(j=1/2) support. This is useful as a deterministic regression test. It is not an independent mathematical validation unless the target values have a separately documented derivation or an independently implemented reference calculation.

The source reports only the pair ((0,1)). The older orientation-covariant (J_{\max}=1/2) diagnostic evaluates all ten pairs, but it is regulator-unsafe for physical HH interpretation. The correct next step is to run all ten pairs in the safe Peter–Weyl implementation and test permutation covariance at (J_{\max}=5/2), with threshold budgets and pre-symmetrization adjointness diagnostics.

## 7. Reachability enumerator versus actual amplitudes

`k5_hda_reachable_basis_gate.py` enumerates representation-allowed spin assignments and multiplies local four-valent intertwiner multiplicities. It deliberately ignores amplitude cancellation. Its values (120 assignments / 816-dimensional upper bound after one (H); 4193 assignments / 24364-dimensional upper bound after an HH pair) are therefore **upper bounds on nonzero amplitude support**, not actual nonzero-support counts.

The enumerator's word-level support logic is consistent with two radial hits and three triangle hits per local term. It does not validate the numerical coefficients, phases, volume matrix elements, or coherent cancellation in the safe-column implementation. Keep the combinatorial and amplitude-level certificates separate.

## 8. Graph-sector shell: basis and projector caveats

The shell script uses sorted full spin/intertwiner keys as basis labels and assigns an abstract graph signature by deleting edges with doubled spin (s_2=0). This is a useful combinatorial sector label. Before interpreting its blocks as physical graph-transition amplitudes, independently establish:
- orthonormality (or the exact Gram matrix) of the full spin-network key basis;
- cylindrical consistency and normalization when a (j=0) edge is removed;
- consistent orientation conventions and vertex relabeling;
- that two different keys with the same active-edge signature remain distinct basis states unless a proven gauge/cylindrical equivalence identifies them.

The projector (P_0) of the compressed-only master is not yet a physical projector. It inherits the omitted-leakage problem described in [BQG_CONSOLIDATED_RESEARCH_AUDIT_2026-11-11.md](BQG_CONSOLIDATED_RESEARCH_AUDIT_2026-11-11.md). Consequently, nonzero cross-graph blocks of that (P_0) are diagnostic properties of the current compressed matrix, not established physical graph-growth amplitudes.

## 9. Concrete acceptance criteria for the next safe-HDA milestone

Do not label the next milestone “safe physical HDA” until all of the following are reported:

1. **Cutoff completeness:** an explicit per-edge hit-count proof for every history used, plus an independent support enumerator at the chosen shell depth.
2. **Adjointness:** action-level bilinear tests for each primitive and node Hamiltonian before symmetrization.
3. **Volume integrity:** raw anti-Hermitian defect, eigensolver residual, and square-root reconstruction residual.
4. **Pruning control:** one coherent aggregation policy, threshold ladder, deterministic order tests, and cumulative discarded-norm budget.
5. **Pair covariance:** all ten oriented node pairs at safe cutoff, with permutation covariance defects.
6. **Graph leakage:** coherent leakage Gram matrices, not only scalar per-column outside norms.
7. **HDA target:** compare the full graph-changing commutator with the expected discrete structure function and volume coefficient, not merely its fixed-sector projection.
8. **Regulator convergence:** repeat at increasing cutoff/shell depth where computationally feasible and compare embedded operators/projectors.

Until these pass, the accurate status is: **regulator-safe finite HH column under a stated cutoff, with important numerical-certification obligations outstanding**. It is not a full HDA closure result.
