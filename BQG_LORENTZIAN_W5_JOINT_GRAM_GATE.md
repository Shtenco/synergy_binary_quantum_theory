# Полный лоренцев W5: совместный Gram-тест и границы доступных данных

Дата: 2026-11-10

## 1. Цель

Для того же входного пространства
\[
W_5=\operatorname{span}\{|K=0\rangle,|K=2\rangle,|K=4\rangle,|K=6\rangle,|K=8\rangle\}
\]
нужно получить евклидову карту \(A:W_5\to\mathcal H_{out}\) и полную лоренцеву карту \(B:W_5\to\mathcal H_{out}\), с одним и тем же явно зафиксированным выходным базисом, порядком строк, фазовой конвенцией и нормировкой.

Тогда вычисляются:
\[
G_{EE}=A^\dagger A,\qquad
G_{EL}=A^\dagger B,\qquad
G_{LL}=B^\dagger B.
\]

Для полной суммы \(H=c_EA+c_LB\):
\[
H^\dagger H=
|c_E|^2G_{EE}+c_E^*c_LG_{EL}
+c_L^*c_EG_{EL}^\dagger+|c_L|^2G_{LL}.
\]
Совместный нулевой сектор суммы существует тогда и только тогда, когда \(\ker H\ne\{0\}\). Отдельно проверяется общий нуль двух карт через вертикально составленное отображение \((A,B)^T\), чей Gram равен \(G_{EE}+G_{LL}\).

## 3. Почему нельзя восстановить перекрёстный Gram из старого евклидова Gram

Знание \(A^\dagger A\) определяет внутренние произведения столбцов \(A\), но не их взаимную ориентацию относительно столбцов \(B\) в общем выходном пространстве. Поэтому \(A^\dagger B\) не определяется из \(A^\dagger A\) и \(B^\dagger B\) по отдельности.

Нельзя просто сложить два спектра или объявить отсутствие совместного ядра суммы из положительности евклидова Gram: лоренцев вклад может интерферировать с евклидовым вкладом в общей выходной компоненте. Нужны реальные амплитуды и согласованная идентификация выходных состояний.

## 4. Воспроизводимый численный gate

Скрипт [scripts/bqg_lorentzian_w5_joint_gram_gate.py](scripts/bqg_lorentzian_w5_joint_gram_gate.py) принимает JSON с:
- `input_basis_K = [0,2,4,6,8]`;
- `output_basis_id` — идентификатор общего упорядоченного выходного базиса;
- комплексными матрицами `A` и `B`, сериализованными как пары `[real, imag]`;
- коэффициентами нормировки `c_E`, `c_L`.

Он вычисляет \(A^\dagger A\), \(A^\dagger B\), \(B^\dagger B\), спектр и сингулярные числа полной суммы, а также отдельный тест общего нуля пары карт. Проверяются размерности, конечность элементов, базис W5 и совпадение размерностей/идентификаторов выходного пространства.

Пример запуска:

```bash
python scripts/bqg_lorentzian_w5_joint_gram_gate.py input_w5_maps.json --output result.json
```

Синтетические тесты скрипта проверяют алгебраическую корректность вычислительного конвейера, но не являются физическим результатом BQG.

## 5. Что требуется получить из первичного генератора

1. Сырые комплексные столбцы \(A\) для пяти входных состояний W5, а не только Gram.
2. Сырые комплексные столбцы \(B\), вычисленные из полного Lorentzian constraint в том же выходном базисе.
3. Точное определение лоренцева члена и его параметров (включая Barbero–Immirzi \(\gamma\), порядок регуляторных пределов и факторные соглашения).
4. Доказательство, что обе карты имеют одну и ту же область определения и общий выходной сектор; если выходные пространства различны, физически обоснованное отображение/вложение между ними.
5. Нормировочные коэффициенты \(c_E,c_L\) из принятого определения полного ограничения, а не подгонка для получения ядра.
6. Контроль численной ошибки амплитуд, устойчивость ранга и интервальную/мультипрецизионную проверку малых сингулярных чисел.
